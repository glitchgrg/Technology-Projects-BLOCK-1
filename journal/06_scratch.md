Scratch uses visual programming blocks to perform the same calculation as the other programs. First, create a variable x and set it to 5. Then change x by 3, making its value 8, and use a say block to display the result.

This is similar to the C, C++, and Python programs because they all add 3 to 5. The difference is that Scratch uses visual blocks instead of typed code, making the program easier to understand visually.
