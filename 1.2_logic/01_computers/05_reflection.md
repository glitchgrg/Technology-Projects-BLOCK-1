* What surprised you about computer hardware?
* I was surprised by how different hardware components work together to process data and run programs. * What challenges did you face?

I addressed this challenge by researching component functions and checking my Lenovo laptop's specifications. * What did you learn about embedded systems?
* I learned that embedded computers combine several components on a single board to save space, reduce cost, and perform specific tasks efficiently. Components such as GPIO pins and communication interfaces allow these devices to connect with other equipment. Embedded systems are useful in robotics, automation, education, and the Internet of Things (IoT).
