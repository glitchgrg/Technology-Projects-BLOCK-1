# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---Hardware refers to the physical components of a computer that we can see and touch. Examples include the keyboard, mouse, monitor, CPU, motherboard and RAM. Each component performs a specific function. Hardware allows a computer to receive input, process data, store information and display useful output to users.

## Explain Software
Write **at least 50 words** explaining what software is.
---Software is a collection of programs and instructions that tell a computer how to perform tasks. Unlike hardware, software cannot be physically touched. Examples include Windows, Microsoft Word and web browsers. Software helps users create documents, browse the internet, manage files and operate computer hardware efficiently for different purposes.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make computers function correctly. Software provides instructions, while hardware executes them. For example, when typing, the keyboard sends input, software processes it, and the monitor displays the text. Without hardware, software cannot run, and without software, computers cannot perform useful tasks.
