| Component | Function |
|-----------|----------|
| SoC |Combines the processor and other essential functions on one chip.|
| GPIO |Connects sensors, LEDs, and other electronic components. |
| USB |Connects peripherals such as a keyboard, mouse, and USB drive. |
| HDMI |Connects the Raspberry Pi to a monitor or TV. |
| Power |Supplies electrical power to the board. |
| microSD |Stores the operating system, programs, and files. |
| Network |Provides wired network connectivity through Ethernet. |
| Wireless |Enables Wi-Fi and Bluetooth communication. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.
Many components are integrated into a single board in embedded computers such as the Raspberry Pi to make them compact, efficient, and affordable. The processor, memory, connectivity ports, and input/output interfaces work together to perform different tasks. This design saves space and reduces the need for separate hardware components. GPIO pins allow the board to communicate with sensors and electronic devices, while USB and HDMI ports connect external peripherals. Network and wireless features enable communication with other devices. Integrated components also make embedded computers easier to use in projects such as robotics, automation, education, and the Internet of Things (IoT).
